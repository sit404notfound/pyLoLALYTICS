# LoL Auto Matchup Opener

League of Legendsの試合開始時に, 対面レーンのLolalyticsマッチアップページを自動でブラウザに表示するPythonスクリプトである。

## 概要

Riot Games公式の「Live Client Data API」を利用し, クライアントからローカルホスト経由で試合情報を取得する。ロード画面に入ったタイミングで自身のレーンと対面のチャンピオンを自動判定し, Lolalyticsのビルドページを開く。
メモリの不正な読み取り等は行わないため, 利用規約違反（BAN）のリスクなく安全に使用できる。

## 特徴

* **言語設定フリー**: クライアント内部の英語データ（`rawChampionName`）を参照するため, 日本語クライアント環境でも正常に動作する。
* **特殊なレーン・チャンピオン名の補正**: API上の `UTILITY` を `support` へ変換し, `MonkeyKing` を `wukong` へ変換するなど, LolalyticsのURL仕様に合わせた自動補正を行う。
* **自動待機・復帰**: 試合終了後は自動で待機状態に戻り, 次の試合が始まると再び動作する。

## 必要要件

* Python 3.x
* `requests` ライブラリ

## 導入手順

1. Python環境を用意する。
2. コマンドプロンプトまたはターミナルで, 必要なライブラリをインストールする。
   ```bash
   pip install requests
   ```
3. `matchup_auto_opener.py` を任意のディレクトリに配置する。

## 使用方法

1. スクリプトを実行する。
   ```bash
   python matchup_auto_opener.py
   ```
2. スクリプトを起動した状態のまま, League of Legendsでマッチメイキングを行い, 試合を開始する。
3. チャンピオンピックが完了しロード画面に移行すると, 既定のブラウザで対面のマッチアップページが自動的に開く。

## 注意事項

* **タブの指定について**: Lolalyticsの仕様上, URLパラメータで「Most Common Build」のタブを直接指定して開くことはできない。デフォルトでは「Highest Win Build」が表示されるため, 必要に応じて手動で切り替えること。
* **対象ゲームモード**: サモナーズリフトなどのポジション（レーン）情報が存在するモードでのみ動作する。ARAM等のポジション割り当てがないモードでは動作しない。

## 今後の実装予定

* **Most Common Buildの自動取得・表示**:
  LolalyticsのHTMLスクレイピングまたは非公式ライブラリを導入し, URL遷移に頼らず「Most Common Build」のルーン・アイテムデータを直接取得する。
* **軽量GUI / オーバーレイ表示の実装**:
  ブラウザを開く代わりに, PyQtやTkinter等を用いた小型のオーバーレイウィンドウをゲーム画面上（またはサブモニター）に表示し, 必要なマッチアップ情報のみをコンパクトに確認できるようにする。
* **LCU API連携によるルーン自動適用**:
  League Client Update (LCU) APIと連携し, 取得した推奨ルーンページをワンクリック（または自動）でクライアントに直接インポートする機能を実装する。
* **レーンスワップへの手動切り替え対応**:
  試合開始後に敵のレーンスワップが発生した場合, ホットキー等で再判定・手動切り替えを行える機能を追加する。
